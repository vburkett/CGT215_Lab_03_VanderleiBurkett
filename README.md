#CGT215_Lab_03_VanderleiBurkett
A small project that allows the user to choose which basic math function they want to perform between two numbers A and B from Addition, Subtraction, Multiplication, and Division.

#Use
The first initial choice input must be an integer from 1-4, each choice type is shown on initial startup. A is always the first variable in the equation, so make sure to select your values in the correct order so you don't get an unexpected answer.
